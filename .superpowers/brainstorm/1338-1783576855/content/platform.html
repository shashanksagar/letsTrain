What platform should letsTrain run on?

This shapes the entire tech stack and user experience. Pick the one that fits how you'll use the app most.

A

Web App (Browser)

Runs in any browser on desktop or mobile. No install required. Easy to share and update. Best for tracking and planning sessions at a desk.

B

Mobile App (React Native / Expo)

Native iOS and Android. Works offline, push notifications, quick log during a workout. Best for use in the gym on your phone.

C

Web + Mobile (PWA)

Progressive Web App — one codebase, installable on any device, works offline. Desktop planning + mobile gym use with a single build.
