letsTrain — App Architecture

React PWA + Supabase + Vercel. All free tier. Dark Teal design system.

Core Modules

1

Onboarding & Fitness Profile

Multi-step wizard: name, age, weight, height, experience level, goal, available equipment, days/week, session length, overload preference. Saved to Supabase user profile.

2

Program Generator

Algorithmic engine that builds a full weekly program from the profile. Targets all muscle groups. Applies periodization (linear for beginners, undulating for intermediate/advanced). Programs: Full Body 3x, Upper/Lower 4x, PPL 5–6x.

3

Workout Logger

Active workout screen: current exercise, sets × reps × weight, rest timer, notes. Logs every set to history. Suggests next weight based on overload mode.

4

Progress Dashboard

Volume over time, strength curves per exercise, bodyweight trend, streak calendar, PRs. Charts using Recharts.

5

Exercise Library

~150 exercises tagged by muscle group, equipment, movement pattern. Filterable. Each exercise has instructions + target muscles diagram.

Tech Stack

Frontend
React 18 + Vite
TypeScript, TailwindCSS, Recharts, PWA plugin
Backend
Supabase (free)
PostgreSQL, Auth, Row-level security, Realtime
Hosting
Vercel (free)
PWA, auto-deploy from git, custom domain
Program Logic
TypeScript engine
Pure functions, runs client-side, no AI API costs
